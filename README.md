# Lumina Air Mouse

A high-performance "Air Mouse" using Python, MediaPipe, and OpenGL.

## Installation

```bash
uv sync
```

## Usage

Run the air mouse directly:

```bash
uv run airmouse
```

## Gestures
- **Move Cursor**: Index finger.
- **Click**: Dwell on a point for 0.8s.
- **Rotate 3D Objects**: Pinch (index + thumb) and move.
- **Grab & Move**: Fist and move.
